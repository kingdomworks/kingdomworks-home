Chris Pawlukiewicz Dev Alerts: Sign-Up

Chris Pawlukiewicz Dev Alerts is a notification program run by Chris Pawlukiewicz, an individual software developer (sole proprietor). It sends automated status alerts from his software development tools: when a development task is finished, when a task is blocked and needs a decision, or when a build or deployment error occurs. It does not send marketing or promotional messages.

Every alert is always shown in the development tools themselves. Text message (SMS) alerts are optional: you can sign up without agreeing to receive text messages.
