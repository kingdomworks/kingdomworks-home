KingdomWorks Agent Alerts: SMS Opt-In

KingdomWorks Agent Alerts is an SMS notification program from KingdomWorks LLC, owned and operated by Chris Pawlukiewicz. It sends automated text messages from KingdomWorks LLC's internal software agents, letting the subscriber know when a long-running task is finished, when a task is blocked and needs a decision, or when an error occurs. This program is for internal use by KingdomWorks LLC and its owner. It does not send marketing or promotional messages.

You're subscribed to KingdomWorks Agent Alerts.

You'll receive a confirmation text: "KingdomWorks LLC: You're subscribed to KingdomWorks Agent Alerts. Msg frequency varies, up to 10/day. Msg & data rates may apply. Reply HELP for help, STOP to opt out."
